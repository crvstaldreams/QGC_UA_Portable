# Редактор українського перекладу QGroundControl-UA

Запуск:

```powershell
.\tools\run_translation_editor.ps1
```

Скрипт сам завантажує вихідні `.ts` файли закріпленої версії QGroundControl v5.0.8 у локальну папку `.translation-workspace` і відкриває GUI-редактор.

У редакторі можна:
- шукати англійський текст, поточний переклад або контекст;
- бачити QML/C++ контекст та розташування рядка;
- задавати переклад тільки для конкретного контексту;
- за потреби робити глобальну заміну для однакового англійського тексту;
- фільтрувати тільки власні правки.

Ручні правки зберігаються у `translations/uk_manual_overrides.json`.

Під час CI-збірки цей файл має вищий пріоритет, ніж автоматичний словник і машинний переклад. Тому виправлена вручну фраза не повинна знову псуватися генератором.
